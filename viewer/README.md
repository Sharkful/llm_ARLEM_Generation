# Viewer

3D visualization tool for ARLEM lab JSON assets.

Reads a lab JSON file (e.g. `Artifacts/Data/Processed/Optomized_moon_lab_final.json`) and renders
the scene objects — prefabs, positions, scales — in an interactive 3D view.

See [`arlem_preview_toolkit/README.md`](arlem_preview_toolkit/arlem_preview_toolkit/README.md) for full documentation, including installation and CLI reference.
